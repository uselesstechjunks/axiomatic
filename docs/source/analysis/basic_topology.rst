********************************************************************************
Metric Spaces
********************************************************************************

.. note::
    * **Metric Space**: A set :math:`X` with a function :math:`d:X\times X\to\R_{\ge 0}` that is positive definite, symmetric, and satisfies the triangle inequality.
    * **Open Set**: :math:`E\subseteq X` is open if every point of :math:`E` is an interior point.
    * **Closed Set**: A set is closed if it contains all of its limit points.

********************************************************************************
Compact Sets
********************************************************************************

.. note::
    * **Compactness**: A set is compact if every open cover admits a finite subcover.

.. tip::
    **Heine--Borel**: A subset of :math:`\R^k` is compact iff it is closed and bounded.
