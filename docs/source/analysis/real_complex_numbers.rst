################################################################################
The Real and Complex Number Systems
################################################################################

********************************************************************************
Groups
********************************************************************************

.. note::
    * **Group** :math:`(G,+,0)` consists of a set :math:`G` and a binary operation :math:`+` that is closed, associative, has an identity element :math:`0`, and gives each :math:`x\in G` an inverse.
    * **Abelian Group**: A group where :math:`x+y=y+x` for all :math:`x,y\in G`.

********************************************************************************
Fields
********************************************************************************

.. note::
    * **Field** :math:`(F,+,0,\cdot,1)` satisfies the group axioms for :math:`+` and :math:`\cdot` along with distributivity: :math:`x\cdot(y+z)=x\cdot y+x\cdot z`.

********************************************************************************
Ordered Sets
********************************************************************************

.. note::
    * **Ordered Set**: A set equipped with a total order relation.
    * **Least Upper Bound Property**: Every nonempty subset that is bounded above has a supremum.

********************************************************************************
The Real Field
********************************************************************************

.. note::
    * **Real Numbers**: There exists an ordered field :math:`\R` with the least upper bound property that contains :math:`\Q` as a subfield.

********************************************************************************
The Complex Field
********************************************************************************

.. note::
    * **Complex Numbers**: :math:`\C` consists of ordered pairs :math:`(a,b)` with operations

        .. math:: (a,b)+(c,d)=(a+c,b+d),\qquad (a,b)(c,d)=(ac-bd,ad+bc).
